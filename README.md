# Slapdash-Seminar

매주 모여 아무 주제나 대충 발표하는 모임, 대충하는발표회를 관리하는 앱이다.
일정 맞추기, 디스코드 공지, 발표 자료와 녹화 올리기를 한곳에서 한다.

## 기능

| 기능 | 내용 |
|---|---|
| 일정 | 팀장이 요청하면 회원이 가능한 시간을 넣는다. 겹치는 후보를 순위 투표로 정하고 확정하면 디스코드에 공지한다 |
| 공지 | 템플릿을 골라 빈칸을 채우고 팀 디스코드 공지방으로 보낸다 |
| 파일 | 발표 녹화와 자료를 올린다. PC 앱은 지정 폴더의 파일을 바로 고를 수 있다 |
| 팀 | 한 회원이 여러 팀에 든다. 초대 코드로 들어오고 팀마다 역할이 다르다 |
| 관리자 | 앱 전체 회원과 공지를 관리한다 |

## 기술

| 부분 | 기술 |
|---|---|
| 앱 | Flutter. 스마트폰(Android, iOS), PC(Windows, macOS), 웹을 한 코드로 만든다 |
| 인증·데이터 | Supabase 셀프호스팅 |
| 보조 서버 | Go. 후보 시간 계산과 디스코드 발송 |
| 서버 | 미니PC 한 대, Docker Compose, Caddy |

## 기여하는 법

main 에는 PR 로만 들어간다. 모듈 하나에 PR 하나다.
PR 본문은 `.github/pull_request_template.md` 를 채우고, `pr-form` 검사를 통과해야 병합된다.
자세한 순서와 모듈별 브랜치 이름은 [CLAUDE.md](CLAUDE.md) 에 있다. 저장소 규칙은 [.github/rulesets/README.md](.github/rulesets/README.md) 에 있다.

비밀값(키, 토큰, 비밀번호, `.env`)은 올리지 않는다. 이 저장소는 공개다.
