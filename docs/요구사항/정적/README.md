# 정적 요구사항

과제가 처음 정한 틀이다. 다른 모든 문서와 코드가 이 위에 선다. 바꾸려면 최소 두 사람이 동의해야 한다.

## 에이전트는 고치지 않는다

Claude, Codex 등 AI 에이전트는 이 폴더를 읽기만 한다. 일하다가 정적 요구사항과 맞지 않는 일을 만나면 멈추고 사람에게 묻는다. 우회해서 고치지 않는다. PR 을 대신 승인하지도 않는다.

막는 곳은 셋이다.

| 막는 곳 | 하는 일 | 못 막는 것 |
|---|---|---|
| `.claude/settings.json` | Claude Code 의 파일 수정 도구가 이 폴더를 고치지 못하게 거부한다 | 셸 명령 |
| `.claude/hooks/static_req_guard.py` | 상대 경로로 쓰기, 셸 명령으로 쓰기, 보호 장치(설정, 훅, CODEOWNERS) 고치기, 훅 끄기, `gh pr review --approve` 를 막는다 | 변수나 스크립트가 경로를 조립해 쓰는 경우. Python 이 없는 PC. Claude Code 가 아닌 에이전트 |
| `.github/CODEOWNERS` 와 코드 오너 승인 | 이 폴더나 보호 장치를 바꾼 PR 은 코드 오너 한 명이 승인해야 병합된다. PR 을 연 계정은 자기 PR 을 승인할 수 없으니 두 사람이 필요하다 | 한 사람이 두 계정을 쓰는 경우. 다른 팀원의 계정으로 에이전트가 승인하는 경우 |

마지막 관문은 GitHub 의 승인이다. 앞의 두 겹은 Claude Code 가 실수로 고치는 일을 일찍 막을 뿐이다. 승인 규칙은 `.github/rulesets/README.md` 의 "코드 오너 승인을 켤 때" 를 마쳐야 실제로 걸린다.

훅은 명령을 글자로만 보므로 반대로 지나치게 막기도 한다. 정적 경로가 나오는 명령에서 Python, Node, 셸 같은 인터프리터를 실행하면 읽기여도 막힌다. `docs/요구사항` 안에서 `echo 정적 > 가변/a.md` 처럼 `정적` 이라는 낱말을 따옴표 없이 쓰는 명령도 막힌다. 읽을 때는 Read 도구나 `cat`, `grep` 을 쓰고, 가변 문서는 Edit 도구로 고친다.

훅은 Python 3 으로 돈다. `python3` 이나 `python` 이 없으면 훅이 돌지 않고, 그때는 첫 겹과 GitHub 승인만 남는다.

## 사람이 바꿀 때

1. 이슈를 연다. 제목은 `[정적 요구사항] <바꿀 것>` 이고, 왜 바꿔야 하는지와 영향을 받는 모듈을 적는다.
2. 팀이 합의하면 사람이 직접 고쳐 PR 을 연다. 모듈은 `골격` 으로 고른다.
3. PR 을 연 사람이 아닌 코드 오너가 내용을 읽고 승인한다. 승인 뒤 커밋을 더 올리면 승인이 풀리니 다시 받는다.
4. 바뀐 내용을 `.claude/memory/skeleton/결정.md` 에 결정으로 남긴다. 가변 요구사항 중 부딪히는 것이 있으면 같은 PR 이나 바로 다음 PR 에서 고친다.
