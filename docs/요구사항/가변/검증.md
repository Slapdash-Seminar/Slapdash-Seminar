# 검증 기준과 인수 시험

- 담당: 전재민(시험). VR 행은 그 모듈 담당도 고친다
- 쓰는 법: `README.md`

## 검증 기준 (VR)

VR 하나는 FR 하나 이상을 확인한다. ID 는 `VR-<모듈 약어>-번호` 다. 기대 결과는 눈으로 볼 수 있거나 명령으로 잴 수 있게 쓴다.

- 옮겨 올 것: 옛 VR-01 ~ VR-18. 모듈별로 나눠 새 ID 를 단다

| ID | 확인하는 FR | 하는 일 | 기대 결과 | 상태 | 근거 |
|---|---|---|---|---|---|

## 인수 시험 (AT)

1차를 끝냈다고 말하려면 통과해야 하는 시험이다.

- 옮겨 올 것: 옛 AT-01 ~ AT-05

| ID | 시험 | 통과 기준 | 상태 | 근거 |
|---|---|---|---|---|
