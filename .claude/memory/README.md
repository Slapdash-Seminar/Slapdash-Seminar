# memory

팀이 함께 읽는 기록이다. 각자 Claude 설정 폴더(`~/.claude`)의 개인 메모리와는 다르다. 팀원이 알아야 할 것은 여기에 쓴다.

모듈마다 폴더 하나다. 폴더 이름은 브랜치 머리와 같다. 쓰는 법은 `.claude/rules/work-sharing/memory 쓰는 법.md`.

| 폴더 | 모듈 | 담당 |
|---|---|---|
| `skeleton/` | 골격 · 공통 레이아웃 | 김도원 |
| `member/` | 회원 | 김도원 |
| `team/` | 팀 | 정다우 |
| `schedule/` | 일정 | 김도원 |
| `notice/` | 공지 | 신강민 |
| `file/` | 파일 | 신강민 |
| `admin/` | 관리자 | 정다우 |
| `alert/` | 알림 | 정한 뒤 적는다 |
| `infra/` | 인프라 · 운영 | 정다우 |
| `_공유 대기/` | 공유하지 못한 작업의 임시 기록 | 누구나 |

- 시작할 때는 맡은 모듈의 `진행.md` 맨 위와 `결정.md`, 그리고 `_공유 대기/` 를 읽는다.
- 지금 하는 일은 여기가 아니라 Draft PR 로 보인다(`gh pr list --state open`).
