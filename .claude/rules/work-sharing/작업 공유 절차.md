# 작업 공유 절차

함께 일하는 사람(과 그 사람의 Claude)이 헤매지 않게, 하는 일을 늘 보이는 곳에 둔다.
보이는 곳은 두 군데다. **지금 하는 일은 Draft PR**, **끝난 일과 결정은 `.claude/memory/<모듈>/`**.
Claude 는 스킬 `work-share` 로 이 절차를 밟는다.

## 시작할 때

1. `git pull` 로 main 을 받고 `git fetch --prune` 으로 원격 브랜치를 맞춘다.
2. 같은 모듈에서 누가 무엇을 하는지 본다. 네 곳을 다 본다.
   - 열린 PR: `gh pr list --state open --search "<모듈>: in:title"`
   - PR 없는 브랜치: `git branch -r --list "origin/<모듈>/*"`. PR 을 못 연 사람은 브랜치만 올린다(`공유 못 할 때.md`).
   - 이슈: `gh issue list --state open --search "[작업 공유] in:title"`
   - `.claude/memory/<모듈>/진행.md` 의 맨 위 몇 줄, `결정.md`, `.claude/memory/_공유 대기/` 의 그 모듈 파일.
3. 같은 모듈에 진행 중인 일이 있으면 시작하지 않는다. 그 PR(없으면 이슈)에 댓글로 무엇을 하려는지 쓰고 담당자와 정한다.
   - 범위를 나눠 따로 하기로 했으면, 나눈 범위를 그 댓글에 남기고 새 브랜치를 딴다. 범위가 겹치는 Draft PR 을 둘 두지 않는다.
   - 이어 받기로 했으면 새 브랜치를 따지 않고 그 브랜치에서 이어 한다. `진행.md` 맨 위에 "인수인계" 줄을 쓴다.
   - 답이 없으면 사용자에게 알리고 기다린다. 남의 브랜치에 push 하지 않는다.
4. 브랜치를 따고(`.claude/rules/repo-rules/모듈과 브랜치.md`), `.claude/memory/<모듈>/진행.md` 맨 위에 "시작" 줄을 쓴다.
5. 커밋해서 push 하고 Draft PR 을 연다. 제목은 `<모듈>: <요약>`. 본문은 한 줄이면 된다("작업 중, 무엇을").
   이제 팀원이 `gh pr list` 로 이 일을 본다.

## 다시 시작할 때 (세션이 예고 없이 끊긴 뒤)

끊기기 전에 기록하지 못했을 수 있다. 이어 하기 전에 로컬과 원격을 맞춰 본다.

1. `git status` 로 커밋하지 않은 변경을 본다. `git log --oneline @{u}..HEAD` 로 push 하지 않은 커밋을 본다.
2. `gh pr list --author @me --state open` 과 `진행.md` 맨 위 줄을 대조해, 끊기기 전 마지막 기록이 실제 상태와 맞는지 본다.
3. 빠진 것이 있으면 커밋·push 하고 `진행.md` 맨 위에 "이어 받음" 줄을 쓴다. 그 줄에 끊긴 사이 기록에서 빠졌던 것을 적는다.
4. `.claude/memory/_공유 대기/` 에 내가 쓴 파일이 있으면 이제 올릴 수 있는지 본다(`공유 못 할 때.md`).

## 하는 동안

- 결정이 생기면 그 자리에서 `.claude/memory/<모듈>/결정.md` 에 쓴다. 다른 모듈에 영향이 있으면 그 모듈 `진행.md` 에도 한 줄 쓴다.
- 작업을 쉬거나 끝낼 때마다(세션을 닫기 전, 사용량 한도가 가까울 때, 대화 압축 전) 커밋하고 push 한다.
  push 가 공유다. 로컬에만 있는 일은 남에게 없는 일이다.
- 남이 알아야 할 막힘이나 질문은 Draft PR 댓글로 남긴다.

## 끝낼 때

1. `진행.md` 맨 위에 "끝" 줄을 쓴다. 남은 일이 있으면 그 줄에 적는다. 커밋하고 push 한다. 끝 줄은 여기서 한 번만 쓴다.
2. 시험·검수를 마치고 PR 본문을 채워 Draft 를 푼다(`.claude/rules/repo-rules/PR.md`). 검수 지적으로 다시 고치게 되면 끝 줄을 새로 쓰지 않고, 남은 일만 새 줄로 더한다.
3. 병합되면 memory 도 main 에 들어가 다음 사람이 읽는다.

## 공유할 수 없을 때

push 를 못 하거나, 저장소 밖에서 일했거나, 세션이 곧 끊기는 때가 있다. `공유 못 할 때.md` 를 따른다. 이미 끊긴 뒤라면 위 "다시 시작할 때".
