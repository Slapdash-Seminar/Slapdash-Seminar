# memory 쓰는 법

memory 는 모듈마다 폴더 하나다(`.claude/memory/<모듈>/`). 폴더마다 파일 셋을 둔다.

| 파일 | 담는 것 | 쓰는 법 |
|---|---|---|
| `README.md` | 이 모듈이 무엇인지, 코드와 문서가 어디 있는지 | 바뀔 때만 고친다 |
| `진행.md` | 시작·끝·막힘·인수인계 | 새 줄을 **맨 위**에 더한다. 옛 줄은 고치지 않는다 |
| `결정.md` | 정한 것과 까닭 | 번호를 붙여 맨 위에 더한다. 뒤집으면 새 번호로 쓰고 옛 줄 끝에 "→ D7 로 바뀜" |

## 줄 꼴

```
진행.md   - 2026-11-18 · @계정 · 시작 · schedule/vote-api · 순위 투표 집계 API
          - 2026-11-19 · @계정 · 끝 · PR #12 · 남은 일: 동점 처리
결정.md   - D3 · 2026-11-18 · @계정 · 동점이면 먼저 넣은 순서로 정한다 · 까닭: 다시 투표를 줄이려고 · PR #12
```

- 날짜, 누가(GitHub 계정), 무엇을 꼭 쓴다. AI 가 썼으면 계정 뒤에 모델을 붙인다(`@계정 · claude-opus-5-5`).
- 한 줄에 한 가지. 길어지면 같은 폴더에 주제 파일을 만들고 줄에서 그 파일을 가리킨다.
- 기획 문서(저장소 밖)의 결정을 옮길 때는 "어디서 왔는지" 를 적는다(예: "요구사항서 FR-07").
- 비밀값, 개인 연락처는 쓰지 않는다.
- 두 모듈에 걸친 결정은 주된 모듈에 쓰고, 다른 모듈 `진행.md` 에 "→ schedule D3 참고" 한 줄을 쓴다. 모든 모듈에 걸치면 `skeleton`.
