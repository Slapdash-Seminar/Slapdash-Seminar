# 공유 못 할 때

공유를 못 해도 기록은 남긴다. 할 수 있는 것 가운데 가장 위 칸을 쓴다. 나중에 공유할 수 있게 되면 그때 올린다.

| 상황 | 할 일 |
|---|---|
| push 는 되는데 PR 을 못 연다 (gh 로그인 안 됨, 검사 실패 등) | 브랜치만 push 한다. 브랜치 이름이 곧 신호다. 커밋 메시지에 상태와 까닭을 쓴다 |
| push 를 못 한다 (인터넷 없음, 권한 없음) | 로컬 브랜치에 커밋하고 `.claude/memory/_공유 대기/` 에 파일을 하나 쓴다(아래 양식). 되는 대로 push 한다 |
| 저장소 밖에서 일했다 (Figma, 서버 설정, 디스코드 봇 설정) | 그 결과를 `_공유 대기/` 파일로 적어 작은 PR(범위 `문서`)로 올린다. 비밀값은 쓰지 않는다 |
| 저장소를 열 수 없다 (휴대폰, 남의 PC) | GitHub 이슈를 연다. 제목 `[작업 공유] <모듈>: <요약>`. 다음에 저장소를 열 때 memory 로 옮기고 이슈를 닫는다 |
| 세션이 곧 끊긴다 (사용량 한도, 대화 압축, 끄기 전) | 하던 일을 멈추고 `진행.md` 에 지금 상태 한 줄을 쓰고 커밋·push 한다. push 를 못 하면 위 둘째 칸 |

## `_공유 대기/` 파일 양식

파일 이름은 `YYYY-MM-DD_<GitHub 계정>_<모듈>_<요약>.md`.

```
- 언제: 2026-11-18 21:30
- 누가: @계정 (작성 모델이 있으면 함께)
- 모듈: schedule
- 한 일:
- 상태: 끝 / 하는 중 / 막힘
- 어디에 있나: 브랜치 이름, 로컬 경로, Figma 페이지 등
- 다음 사람이 알아야 할 것:
```

- 이 파일은 정식 memory 로 옮기면(그 모듈 `진행.md`·`결정.md`) 다음 PR 에서 지운다.
- 시작할 때 이 폴더를 먼저 본다(`작업 공유 절차.md`).
