# 기술 스택

| 부분 | 기술 | 비고 |
|---|---|---|
| 앱 | Flutter | 스마트폰(Android, iOS), PC(Windows, macOS), 웹을 한 코드로. 반응형 웹이 아니라 네이티브 앱이다 |
| 인증·데이터 | Supabase 셀프호스팅 | 로그인은 이메일. 아이디는 받지 않는다 |
| 보조 서버 | Go | 후보 시간 계산, 디스코드 발송 |
| 서버 | 미니PC 한 대 | Docker Compose, Caddy |

- Supabase Studio 는 시스템 운영자만 Tailscale 로 들어간다. 앱 안의 관리 화면은 직접 만든다.
- 화면(UI) 글자는 "관리자", "운영자" 로 쓴다. 문서에서는 서버를 다루는 "시스템 관리자" 와 앱 안 역할을 나눈다.
- 스택을 바꾸는 결정은 `memory/skeleton/결정.md` 에 남기고 이 표를 PR 로 고친다.
