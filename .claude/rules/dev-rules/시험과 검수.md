# 시험과 검수

## 시험

- PR 을 열기 전에 시험을 돌린다. 돌린 명령과 결과를 PR 본문 `시험` 칸에 그대로 적는다.
- 화면이 바뀌면 캡처를 붙인다. 캡처 없는 화면 변경은 시험을 안 한 것으로 본다.
- 시험을 못 돌렸으면 못 돌렸다고 쓰고 까닭을 적는다. 돌리지 않은 시험을 통과로 적지 않는다. PR 양식의 확인 칸 "시험을 돌려 결과를 적었거나, 못 돌린 까닭을 적었다" 는 이 경우에도 체크한다.

## 검수

- 짠 쪽과 검수하는 쪽을 나눈다. 검수 모델은 작성 모델과 달라야 한다. 기본은 Codex 다.
- 검수 결과는 통과, 조건부 통과, 재설계 중 하나다. 재설계면 병합하지 않고 나눔부터 다시 한다.
- 지적을 고치고 다시 검수한 횟수를 센다. 남은 지적은 PR 본문 `남은 지적` 에 적는다.
- 검수 모델을 쓸 수 없는 때(사용량 한도 등)는 PR 을 Draft 로 두고, 본문에 "검수 대기 · 까닭 · 다시 할 때" 를 적는다. 검수 없이 병합하지 않는다.
