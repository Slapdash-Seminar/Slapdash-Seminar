# rules

규칙은 주제마다 폴더 하나다. 필요한 폴더만 연다.

| 폴더 | 담는 것 |
|---|---|
| `repo-structure/` | 저장소 구조. 폴더가 어디 있고 새 것을 어디 두나 |
| `repo-rules/` | 저장소 규칙. 모듈과 브랜치, PR, 비밀값 |
| `dev-rules/` | 개발 규칙. 기술 스택, 커밋, 시험과 검수 |
| `work-sharing/` | 작업 공유. 시작·끝 절차, 공유 못 할 때, memory 쓰는 법 |

## 규칙을 고칠 때

- 규칙도 PR 로 바꾼다. 범위에 `문서` 를 체크하고, 모듈은 규칙이 다루는 모듈(여럿이면 `골격`)로 고른다.
- 새 규칙 파일을 만들면 이 표와 루트 `CLAUDE.md` 의 "상황별로 볼 곳" 에 한 줄을 더한다.
- 파일 하나는 한 화면 안팎으로 짧게 둔다. 길어지면 같은 폴더 안에서 나눈다.
- 규칙은 "무엇을 한다" 를 쓴다. 왜 그렇게 정했는지는 한두 문장만 붙인다. 긴 경위는 memory 에 둔다.
