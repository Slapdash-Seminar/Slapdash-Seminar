# 폴더 구조

지금 있는 것과 앞으로 둘 자리다. 코드 폴더는 첫 코드 PR 이 만든다. 자리를 바꾸려면 이 파일부터 PR 로 고친다.

```
CLAUDE.md                 안내만. 상황별로 어느 파일을 볼지
README.md                 사람이 처음 읽는 소개
.claude/
  rules/                  규칙. 주제마다 폴더 하나 (rules/README.md)
  memory/                 기록. 모듈마다 폴더 하나 (memory/README.md)
  skills/                 Claude 가 쓰는 절차. work-share, module-pr
.github/
  pull_request_template.md   PR 본문 양식
  scripts/check_pr_form.py   양식 검사기 (pr-form)
  workflows/pr-form.yml      검사 실행
  rulesets/                  main 보호 규칙과 근거
app/                      (예정) Flutter 앱. 스마트폰·PC·웹 한 코드
server/                   (예정) Go 보조 서버. 후보 시간 계산, 디스코드 발송
supabase/                 (예정) DB 스키마, 권한, 마이그레이션
infra/                    (예정) Docker Compose, Caddy, 백업 스크립트
```

## 두는 곳 정하기

| 만드는 것 | 둘 곳 |
|---|---|
| 화면, 위젯, 앱 상태 | `app/` 안의 모듈 폴더(회원·일정 등 `.claude/memory/` 와 같은 이름) |
| 서버 API, 계산 | `server/` 안의 모듈 폴더 |
| 테이블, RLS 정책, 마이그레이션 | `supabase/` |
| 배포, 서버 설정 | `infra/` |
| 규칙 | `.claude/rules/<주제>/` |
| 결정, 진행, 인수인계 | `.claude/memory/<모듈>/` |

- 모듈 폴더 이름은 브랜치 머리와 같게 쓴다(`schedule`, `notice` 등). 모듈 목록은 `.claude/rules/repo-rules/모듈과 브랜치.md`.
- `app/`·`server/` 안의 세부 구조는 그 폴더를 처음 만드는 PR 이 정하고, 이 파일에 한 줄 더한다.
