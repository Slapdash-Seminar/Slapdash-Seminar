# 비밀값

이 저장소는 공개다. 한 번 push 한 비밀값은 지워도 이력에 남는다.

- 키, 토큰, 비밀번호, 개인 접속 주소(Tailscale IP, 서버 포트 조합), `.env` 는 커밋하지 않는다.
- 설정 예시는 `.env.example` 에 이름만 두고 값은 비운다. `.gitignore` 가 `.env`, `.env.*` 를 막는다(`.env.example` 은 허용).
- memory 와 PR 본문에도 쓰지 않는다. "어디에 있는지" 만 적는다(예: "미니PC 의 `/srv/app/.env`").
- 실수로 올렸으면 그 값을 바로 폐기하고 새로 만든다. 이력 지우기는 그다음이다. 담당(`infra`)에게 알린다.
