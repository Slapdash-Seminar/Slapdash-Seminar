# 모듈과 브랜치

모듈 하나 = 브랜치 하나 = PR 하나다. memory 폴더 이름도 브랜치 머리와 같다.

| 모듈 | 브랜치 머리 · memory 폴더 | 담당 |
|---|---|---|
| 골격 · 공통 레이아웃 | `skeleton` | 김도원 |
| 회원 (가입, 로그인, 설정) | `member` | 김도원 |
| 팀 (팀 고르기, 팀 설정, 초대 코드) | `team` | 정다우 |
| 일정 (요청, 가능 시간, 후보 산출, 순위 투표, 확정, 겹침) | `schedule` | 김도원 |
| 공지 (템플릿, 작성, 디스코드 발송) | `notice` | 신강민 |
| 파일 (지정 폴더, 업로드, 자료실) | `file` | 신강민 |
| 관리자 (서비스 관리자 화면) | `admin` | 정다우 |
| 알림 | `alert` | 정한 뒤 적는다 |
| 인프라 · 운영 | `infra` | 정다우 |

- 브랜치 이름은 `<브랜치 머리>/<짧은 영문 요약>` 이다. 예: `schedule/vote-api`
- 한 PR 에 두 모듈이 섞이면 나눈다. 모두가 쓰는 공통 부분과 저장소 전체 설정만 `skeleton` 으로 올린다.
- 이 표를 바꾸면 PR 양식(`.github/pull_request_template.md`)의 모듈 체크 칸과 `.claude/memory/` 폴더도 같이 바꾼다. 검사기는 main 의 양식에서 칸 이름을 읽는다.
